# 💫 About Me:
Hi, I'm Kumar Harsh! 👋 

I am a Data Engineer and AI builder with a strong foundation in Mechanical Engineering and Computer Science. I started my programming journey building Android applications and working with Robotics, but I quickly found my true passion in architecting massive data ecosystems and AI integrations. 

Today, as a Manager in the Data Office at Tata Steel, I specialize in building highly scalable Medallion data platforms, real-time streaming pipelines, and predictive GenAI agents. I love turning chaotic data into clean, observable, and elegantly simple business solutions.

**What I'm building today:**
- 🏗️ Architecting cloud-native ETL/ELT pipelines (AWS, Snowflake, BigQuery)
- 🌊 Streaming real-time data with Kafka and Python
- 🧠 Engineering LLM applications and RAG agents using LangChain
- ⚙️ Orchestrating fault-tolerant workflows with Dagster and Temporal.io

*(Feel free to explore my older repositories to see my early roots in Android development, Java, and Arduino-based robotics!)*
